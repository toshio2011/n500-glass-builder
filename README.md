# N500 Glass TV Home — safe builder

Builds [Glass TV Home](https://github.com/aqmangge/glass-tv-home) as a **separate app** for an N500 Android projector, so it can be tested without uninstalling the working [CleanYourTV](https://github.com/Gathin23/cleanyourtv) launcher.

## What this does

- Clones a **pinned upstream Glass TV revision** in GitHub Actions; no Java/Android build tools needed on the phone.
- Changes only the Android **application ID** to `com.n500.glasstvhome`; Java source namespace stays upstream's `com.gathin.tvhome`.
- Renames the visible app to **Glass TV N500**, adjusts the hardcoded screensaver component and location broadcast, and disables upstream's in-app OTA updater, which would otherwise attempt to install the conflicting original APK.
- Builds a signed APK, validates its installed package ID, and uploads it as a downloadable GitHub Actions artifact.
- **Does not connect to, debloat, restore, disable, remove or change your projector.** Installation is separate and requires action on your phone.

## Build APK from GitHub

1. Open [Build N500 Glass TV](https://github.com/toshio2011/n500-glass-builder/actions/workflows/build-n500-glass.yml), then choose **Run workflow** (or check the first push-triggered run).
2. Wait for the `Build conflict-free APK` job to finish with a green tick.
3. Open that run's **Artifacts**, download **N500-Glass-TV-APK**, and unzip to obtain `n500-glass-tv.apk`. This is the APK, not the installer/source kit.

If GitHub Actions is disabled for the repository, enable it from its Actions tab.

## Install with Termux (on the Android phone, same Wi-Fi as projector)

Install Termux from [F-Droid](https://f-droid.org/en/packages/com.termux/). In Termux:

```bash
pkg update -y
pkg install -y android-tools unzip
termux-setup-storage
```

Download the GitHub artifact ZIP on your phone, then move/extract it into `Download` with the Android Files app so `/sdcard/Download/n500-glass-tv.apk` exists.

**Keep CleanYourTV installed. Don't restore, disable or remove it yet.** Save/export the CleanYourTV restore point first.

Determine the projector's IP in CleanYourTV, then:

```bash
adb connect TV_IP:5555
adb devices -l
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell pm list packages -d
adb install /sdcard/Download/n500-glass-tv.apk
adb shell am start -n com.n500.glasstvhome/com.gathin.tvhome.MainActivity
```

Replace `TV_IP` with the projector's LAN IP, and approve the ADB authorization on the projector if asked. The example install assumes Termux has been granted storage access. If needed use `adb install "$HOME/storage/downloads/n500-glass-tv.apk"`.

**Important:** Running `adb install` is safe for the existing launcher because this APK has a *different* package ID. Merely starting it for testing does **not** make it your default Home app.

On the projector, try navigation, app launching, settings, wallpapers and Inputs. If it works, you can choose the new launcher in Android's **Default Home** picker (if available). If not, from connected Termux:

```bash
adb shell cmd package set-home-activity com.n500.glasstvhome/com.gathin.tvhome.MainActivity
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

Test the Home button and **reboot** before considering removal of the old launcher. Some projector firmware overrides third-party Home apps, so the command may fail or revert.

To return to the still-installed CleanYourTV Home app if needed:

```bash
adb shell cmd package set-home-activity com.gathin.tvhome/com.gathin.tvhome.MainActivity
```

If the original Home was already disabled or another app owns Home, inspect the actual `resolve-activity` output before changing further settings. Never disable both launchers.

## Signing, updates and limitations

The initial workflow signs using Android's autogenerated debug keystore on the GitHub runner. **A later run may use a different signing key**, so it may *not* install as an upgrade over this N500 app. Do not assume APKs from different runs will preserve settings; use a persistent signing key for proper future releases. Do not store a private signing key in a public repository.

Upstream is pinned to GitHub commit `bfa48608c79074d5e57b9efeb098a64e7601e3cd` (Glass TV Home 2.6.0 snapshot). This is an independently repackaged build, not an official Glass TV release. It is **not tested on the N500** until installed, and some features such as HDMI input switching depend on projector firmware support.

Upstream license and original authorship remain with [aqmangge/glass-tv-home](https://github.com/aqmangge/glass-tv-home) and CleanYourTV contributors.
